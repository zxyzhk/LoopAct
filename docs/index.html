02 / THE METHOD

A slow plan.
A fast visual correction.

The final denoising transition becomes a feedback interface, so each action can incorporate the latest observation without rerunning the full planner.

01

Propose

VLM + APP

A vision-language backbone and the Action Proposal Planner generate a near-final action chunk.

02

Reuse

ACE + ACC

Action-side representations are encoded once and retained in the Action Context Cache.

03

Refine

VRN · VOE · CMFB

Current visual observations are fused with cached action features to complete the final denoising update.

Explore the architecture+

APP: Action Proposal Planner · VRN: Visual Refinement Network · ACE: Action Context Encoder · VOE: Visual Observation Encoder · CMFB: Cross-Modal Fusion Block · ACC: Action Context Cache.
